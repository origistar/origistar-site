龙头、价值与赛道

彭道富 著，序言“炒股养家”。本书是对投资哲学与逻辑的深度思考：以广义价值为锚，以供求与主要矛盾为逻辑，以赛道和龙头为战场。

一、本书核心观点

1. 股价上涨的根本源动力是“价值”

其他因素都是价值的派生、借口或说辞。作者重新定义广义价值：价值来自四源——争（博弈）、用（使用/业绩）、权（政策/权力）、信（信仰）。

  • 价值排序：有用性（业绩/使用价值）天然最大，权力价值其次，信仰价值与“因争而生”的价值再次。四项全具备者最充分，典型如茅台。
  • 弹性价值：股价短期爆炸性上涨，反应的是预期变化与弹性，不是静态基本面；“基本面好 + 高弹性”才有爆发力。财报落地、预期兑现后，弹性消失，常“利好出尽”。
  • 时间价值：时间赋予标的价值不同；先谈时间，再谈逻辑和方法。逻辑和方法必须臣服于时间维度，“毋与天地斗巧”。
  • 守正出奇：正是最正宗、最大受益的股票（举旗、定海神针）；奇是看似边缘、超预期的股票。无正不起奇，奇永远傍正说事；守正方能出奇。

2. 根本逻辑四支柱

  • 供求关系：最底层逻辑；需求暴涨或供给受限，最好“既让马儿跑，又不让马儿吃草”。
  • 主要矛盾：投资的最大道是社会的主要矛盾（战争、资源、盛世消费、疫情医药等）。
  • 苹果树下（亲力亲为）：重大决策必须御驾亲征，不依赖分析师、研报和新闻，掌握一手情报。
  • 最大公约数：龙头战法的哲学基础是把朋友搞得多多的，即群众基础最广、最容易理解认可传播。

3. 赛道 > 个股

抢钱、抢粮、抢人，都不如抢赛道。透过个股要看到其背后的赛道传奇（如工业大麻之于顺灏股份，A股总赛道之于茅台）。

4. 龙头定义

龙头是头部策略、第一性原理，源于“擒贼先擒王”；是最关键、最具有决定性、最塔尖的因素与股票。龙头是一种思想，一种哲学。

5. 一花三叶 / 一龙三脉

  • 股权/价值龙头：茅台、腾讯、万科（最好赛道+头部公司）。
  • 白马龙头（价值投机）：方大炭素、浙江龙盛、漫步者（基本面与市场情绪共振）。
  • 黑马龙头（妖股）：东方通信、人民网、九鼎新材（人气、情绪、涨停博弈）。

6. 龙头宪法（九则）

  1. 自选股里只放龙头，谁给买点买谁。
  2. 早盘前30分钟，只看几个龙头的走势。
  3. 强制自己只与龙头发生关系。
  4. 有总龙头，就不做分龙头。
  5. 有连板的龙头，就不做反包的龙头。
  6. 有主升的龙头，就不做反抽的龙头。
  7. 有主线的龙头，就不做支线的龙头。
  8. 有明牌的龙头，就不去挖暗线的龙头。
  9. 有市场选出的龙头，就不做自己选的龙头。

7. 心法与风控

  • 最高指南是“心念”/一念，要破技术分析之执；过往不念，当下不杂，未来不迎。
  • 用“银行家逻辑”买卖：天晴借伞（走强买），下雨收伞（转弱卖）。
  • 正法模型：只在“有逻辑 + 有真实上涨信号”的第一象限出手；“有逻辑无信号”是我执，99.99%的人不适合潜伏/死扛。
  • 资金管理比仓位管理重要一百倍。不贷款炒股；熊市把资金转出，证券账户只留<30%；牛市投入股市资金不超过总资产80%。
  • 真正风险：不是回撤，而是“那些你确定无疑的事情，并不如你想象”。不要把“奇迹”当规律。

三、价值论：股价为什么涨？

广义价值四源

价值来源含义书中案例排序
争（博弈/共同价值取向）大家抢、追捧，越涨越有人争儿童抢娃娃熊；艺术品；妖股“越能涨越能涨”再次
用（使用价值/业绩）有用性，业绩定海神针工商银行；方大炭素业绩弹性；茅台天然最大（母价值）
权（权力/政策价值）政府权力、牌照、政策强制背书王府井免税牌照；供给侧改革其次
信（信仰价值）因信称义，相信就有价值特斯拉；赎罪券；宗教文物再次

核心结论：四项全具备是最充分价值性；一项都不拥有，不是零价值，而是负价值。

弹性价值 vs 静态价值

股价炒的是“预期和变化”，不是对已有基本面的映射。出财报后反而可能不涨：因为弹性价值消失了。

  • 方大炭素（石墨电极涨价，弹性巨大）vs 宝钢（赚钱多但弹性小）。
  • 互联网公司1亿利润暴涨 vs 房地产公司卖楼赚更多却不涨（弹性差异）。

守正 vs 出奇

类型定义作用案例
正最正宗、最大受益、最该炒的标的举旗、定海神针、板块风向标迈瑞医疗/鱼跃医疗（呼吸机正）；泰达股份（口罩正）
奇看似边缘、无厘头、出乎意料剑走偏锋、光芒万丈；但拿正说事航天长峰（呼吸机奇）；东方通信（5G奇）；金力永磁（稀土奇）

无正不起奇：没有正兵吸引资金，奇兵无用。守正出奇：先把最正的钱赚了，奇冒出来再做奇。

四、四大根本逻辑

1. 供求关系（最底层逻辑）

萨缪尔森：“如果一只鹦鹉学会了供求关系，它也能成经济学家。”最佳模型：需求端无限增加 + 供给端有瓶颈 = “既让马儿跑，又不让马儿吃草”。

  • 口罩：以前医生用 → 全民每天用（需求暴涨）；熔喷布有供给瓶颈。
  • 腾讯QQ：用户暴增，服务器不够用 → 坚信能赚钱。
  • 石墨电极/方大炭素：供给受限 + 需求爆发。

2. 主要矛盾（投资的最大道）

投资最大道不在K线、指标，而在社会主要矛盾。

  • 战争时期 → 军工；资源紧缺 → 有色；太平盛世 → 消费（茅台、可口可乐）。
  • A股：2006年起“人与房子”矛盾 → 地产、银行、白电长期走牛。
  • 互联网矛盾 → 阿里、腾讯；疫情 → 口罩、医药、在线办公、在线教育。

3. 苹果树下（亲力亲为）

不要依赖二手信息；要亲自调研、御驾亲征。案例：期货苹果（去产地看产量）；索罗斯狙击英镑（亲自接触政要）；猪肉股（亲自去猪场看猪跑）。重仓并持有大龙头，必须亲自挖掘信息，才有信仰和底气。

4. 最大公约数（龙头哲学基础）

哪个股票朋友多多的，哪个就是龙头。龙头必须：容易理解、容易认可、容易接受、便于传播。案例：东方通信、金力永磁、星期六、口罩股都符合“成千上万群众基础”。

五、赛道与对标逻辑

赛道：选择比努力重要

蔡文胜案例：抢注域名、做256导航、投腾讯、做美图，全部押注互联网赛道。腾讯QQ/微信 vs 米聊/MSN：赢在占据互联网/移动互联网赛道关口。抖音/字节跳动：抢流量赛道，让阿里、腾讯都畏惧。结论：抢赛道 > 抢钱抢粮抢人；透过个股要看到赛道传奇。

对标逻辑

先对标大盘环境（牛市/鸡肋/熊市），再对标个股气质。经典个股对标：

  • 片仔癀 = 中药中的茅台
  • 卓胜微 = 科技中的茅台
  • 王府井 vs 中国国旅（免税正标）
  • 东方通信 vs 特力A（妖性、明星气质对标）
  • 星期六 vs 海虹控股（互联网初期气质）

“标”是活的，不能刻舟求剑。对标对象恶化，你的对标分析就失效。

六、先手逻辑（短线核心）

不要跟着龙虎榜第二天买顶级游资的票：等于让他们三步棋，你必输。先手 = 与聪明资金并肩，或更早；在“看懂龙头意图的刹那”立即买。

拳打两不知：

  • 一不知：散户/群众不知（晚上自媒体讨论时，你盘中已买到）。
  • 二不知：自己不完全知（靠厚积薄发的本能/盘感出手）。

结论：速度/先手，在短线中比“全知”更重要。

七、重新定义“龙头”

龙头本质

头部策略、第一性原理；源于“擒贼先擒王”“百万军中取主帅首级”。利弗莫尔“领头羊思想”、欧奈尔“Leader”、巴菲特买各行业NO.1。

一花三叶对比表

类型代表标的核心操作特点
股权/价值龙头茅台、腾讯、万科黄金赛道 + 头部公司长期持有，躺着赚钱
白马龙头（价值投机）方大炭素、浙江龙盛、漫步者基本面 + 市场情绪共振可重仓、趋势主升、不会核按钮
黑马龙头（妖股）东方通信、人民网、九鼎新材人气、情绪、涨停博弈最猛、身位卡位、市场给答案

买卖与见顶

买不到是伪命题：顺灏股份、东方通信、复旦复华、人民网、中信建投在主升中都给过买点。核心是认知不够 / 不敢买。

见顶四信号：

  1. 高位巨阴
  2. 高位跟风阵亡（成光杆司令）
  3. 高位周期退潮（核按钮增多、明星股跳水）
  4. 管理层密集监管（问询函、窗口指导、点名批评等）

分段龙：不连板也是龙（航天长峰、道恩股份、市北高新、浙江龙盛）；领涨才是本质，“龙头本无形，领涨自得之”。

八、心法：破心中贼 & 正法模型

1. 最高指南是“心念”

破技术分析之执：K线、指标是“任你打扮的小姑娘”，服务你的心念。过往不念，当下不杂，未来不迎。

2. 正法模型（四象限）

象限逻辑性信号性（真实上涨）结论
第一象限：正法有有✅ 只买这个
第二象限：我执有无❌ 潜伏/死扛，99.99%人不适合
第三象限：风平浪静无无不动，不亏
第四象限：妄动无有异动❌ 绝大多数人亏钱的主因

3. 大概率 vs 小概率

成龙后K线连板是大概率；事前从100个龙头苗子中，最终成龙的仅5—6个甚至1—2个（小概率）。要研究唯一性/差异点：从“都一样”的连板、形态中，找出它脱颖而出的必然性（宿命基因）+ 偶然性（情绪/事件）。

4. 银行家买卖法

  • 天晴把伞借给你（股票走强、成热点时大胆买）
  • 下雨天把伞收回来（出现危险苗头立即卖）

短线：宁可锦上添花，也不雪中送炭；顺周期而为。

5. 其他破执

  • 不怕盘子大：逻辑硬，大盘股也能妖（光大证券、沪硅产业）。
  • 不怕股价高：注册制下质量 > 价格；疫苗股西藏药业、康华生物等是高价股却最妖。
  • 不恐高：股价“顶到屏幕右上方”是框架效应；晶方科技、美锦能源、宁德时代继续涨。
  • 好公司 ≠ 好股票：还要看弹性、安全边际、估值与周期。
  • 安全寄于选股，不寄于买点：“确定就低吸、不确定就打板”是误区。

九、风控、数据与细节

1. 资金管理 > 仓位管理

  • 不贷款、不套信用卡炒股。
  • 永远留家庭至少1年现金。
  • 熊市把资金转出证券账户，账户内只保留 <30%。
  • 分多账户管理，防黑天鹅。
  • 牛市投入股市资金：若有100万总资产，最多投入 80万。

2. 利好：火上浇油 vs 见光死

结果案例关键原因
火上浇油振德医疗（防疫用品销量大增）、王府井（免税牌照）超预期、处于上升周期、股价在波浪起点
见光死华大基因、宝莱特、高德红外、第一创业（业绩预增）利好在预期内、周期下降、股价在高位顶点

3. 核按钮秘密

  • 主动跌 vs 被动跌：主动下跌（市场没问题，它自己崩）→ 废了；被动下跌（至暗时刻被大盘/战友拖累，战至最后一刻）→ 虽核犹勇。
  • 谁核谁：主力被群众核，没事；群众被主力核，完蛋。
  • 空中蘑菇云：多个一字板后突然跳伞，最难救，因为获利盘厚、无换手断层。

4. 真正风险

原油宝事件：真正风险不是亏损，而是“那些你确定无疑的事情，并不如你想象”。不要把奇迹当规律：恒立实业是特殊环境（壳资源+汽车+科创续命）下的小概率，不能复制为“炒最高板”的规律。

十、功夫在诗外

1. 马后炮正名

围棋复盘、军事总结、商战案例都是“马后炮”；马后炮水平提升，才是进步标志。没有马后炮的马前炮，不是神棍就是骗子。

2. 第二波机会

比尔·盖茨：“人们总是高估新技术出现的第一个五年，但会低估第二个五年。”第一波是概念泡沫（互联网泡沫、口罩首波），第二波才是真正赚钱：阿里/腾讯（互联网第二波），道恩股份/振德医疗（口罩第二波），光大证券（证券第二波）。

3. 小有才华最危险

股市里小有才华不如无才华；必须彻底通透，做到大有才华。“如果爱，请深爱，若不爱，请走开！”

4. 天时/择时

投资也要重视天时（行情/周期）。下降趋势应休息，等增量资金和赚钱效应，而不是换方法。

5. 中医与投资

中医整体观、辨证施治、医缘、五运六气，与投资“主要矛盾、供需、时间价值”相通。核心思想：“正气存内，邪不可干”；投资也要抓主要矛盾、扶“龙头”之正气。

十一、一句话总纲

以广义价值为锚，以供求与主要矛盾为逻辑，以赛道和龙头为战场，以先手、正法、资金管理为心法，敬畏天时，等待史诗级机会，用“大有才华”去拥抱最强者。
