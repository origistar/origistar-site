二、核心框架：收益公式

​$\boxed{p = \delta + \alpha - \gamma}$​

符号 含义 决定因素 你能控制吗？
p 最终投资业绩 —— ——
δ (Delta) 市场整体成绩（β=1时） 选择与市场100%相符的标的 ❌ 边界之外
α (Alpha) 跑赢市场的收益 开始行动之前的谨慎选择 ✅
γ (Gamma) 因自己犯错而损失的收益 自我管理能力 ✅

关键结论：定投者一旦开始，就再也不用纠结选择——一切的α都来自开始之前的谨慎选择；γ趋近于零的方式是“什么都不做”。

三、第一部分：定投策略

3.1 为什么定投有效

定投策略 = 长期持有策略的最有效改良
         = 分批买入 + 坚决不卖 + 长期持有

3.2 “长期”究竟是多久？⭐ 核心概念

长期 = 两个大周期以上 = 穿越至少两次牛熊

一个大周期的构成：

一个大周期 = 下跌的B阶段 + 上涨的A阶段

关于大周期的判断要点：

  • 每一次历史新高只能靠滞后判断认清
  • 判断趋势需要至少两个大周期才有意义
  • 关于趋势的判断最多做到“更可能”
  • 可以把每一次历史最高点当作B阶段的起点

3.3 为什么一定用钱去赚钱

人一生78年的时间分配（Anna Vita 数据）：

活动 时间
睡觉 28.3年
工作（可出售时间） 10.5年
社交媒体 9年
做家务 6年
吃喝 4年
教育 3.5年
梳妆打扮 3年
购物 2.5年
照顾小孩 1.5年
通勤 1.3年

核心洞察：可供出售的时间只有10.5年，即便拼尽全力也最多19.5年，根本无法“翻倍”。而钱是不休息的——它一年365天、每天24小时为你工作。

富兰克·奈特的观点：决定富有的三条件——出身、运气、努力，努力是最微不足道的。

3.4 我们到底在用什么定投

定投的三重资源：钱 + 时间

个人商业模式的三连胜升级（Trifecta）：

升级前 → 升级后
一份时间出售一次 → 一份时间出售很多次
只会用钱消费 → 会用钱赚钱（投资）
只会用钱投资 → 还会用时间投资

为什么基金经理做不到定投：

99.99%的基金管理者手中的资金都有时间期限限制。资金有期限，风险就是1；资金无期限，风险就是0。根本没有0.2或0.8。

五、第三部分：定投执行中的心理建设

5.1 鸡蛋投资法则 ⭐⭐

🥚 熟鸡蛋结构（你的钱）：
┌─────────────────┐
│   ╭─────────╮   │
│   │  蛋黄    │   │  ← 日常必需开销
│   │ ╭─────╮ │   │
│   │ │蛋白 │ │   │  ← 抵御风险的储蓄（要够厚！）
│   │ │╭───╮│ │   │

大多数人投资失败的原因：低估了生活中的意外成本——没想到蛋白的部分竟然要那么厚。

定投用的钱必须满足：

  • 无成本
  • 无期限
  • 能陪你穿越至少两次牛熊
  • 加上足够的备用金

5.2 场外持续赚钱能力 ⭐

成功践行定投策略的核心之一在于践行者的场外赚钱能力。

  • 定投策略本身三个字总结：买买买
  • 真正的难点：长期持续地投入，意味着必须有长期持续的场外赚钱能力
  • 场内是拼交通工具的地方，场外是拼脚力的地方
  • 场外赚钱能力才是检验一个人是否真的进步的最靠谱方式

销售的核心是信任——建立信用需要20年，摧毁它只需5分钟。

第一次低谷  →   第一次收获 →   第二次低谷  →   再一次收获 →   星辰大海
(漫长)         (短暂)        (更漫长)        (短暂)       (平静)

横财效应（House Money Effect）：赌徒把赢来的钱不当钱花——极少数有上进心的人用它做不合格的投资，“凭运气赚到的钱凭实力全部亏掉”。

六、第四部分：我们就是非常不靠谱

6.1 人脑的不靠谱实验 ⭐

框架效应实验（De Martino等）：

框架 描述 参与赌博比例
收益框架 “你可以保留50英镑中的20英镑” 43%
损失框架 “你将会失去50英镑中的30英镑” 62%

结论：原来很多人之所以冒险，根本不是因为勇敢，而是因为害怕——害怕的东西其实并不存在。

杏仁核的作用：当无法抵制损失厌恶时，杏仁核处于激烈激活状态——这就是“我明明知道该怎么办，可我就是控制不住”的生物学根源。

冷静的定义：不管什么事，都需要三个角色分别处理一次，而后交由车夫决定。

实操方法：三个角色先折腾一会，身体先别动——5分钟之后再行动，永远有效。

6.3 镜像效应⭐⭐⭐

对长期的认知就是那面镜子，总是生成惊人镜像效应的那面镜子。

镜子外 镜子里
价格下跌→恐慌逃跑 价格下跌→高兴（能买更便宜的筹码）
投资有风险→不敢投 不投资的风险才大
现金是安全的 现金长期必然贬值
成功是终点 成功是新起点

市场有效性的镜像理解：

  • 长期来看，市场倾向于相当有效
  • 任何一个单独时刻，市场总是极端无效
  • 市场正是因为时时刻刻无效，所以才有存在的意义，才有可把握的机会
